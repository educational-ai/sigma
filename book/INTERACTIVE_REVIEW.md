# Сигма — стандарт качества и критического ревью живых виджетов

Свод правил для нативных интерактивных визуализаций (`scripts/interactive/`,
монтируются как `<div data-sigma-widget="...">`). Планка — **distill.pub**.
Этот файл — рубрика adversarial-ревью: каждый виджет проходит её перед «готово».

## 0. Главный принцип (нарушение = блокер)
**Никаких кнопок «Запустить».** Взаимодействие — ползунок / перетаскивание / поворот /
клик — даёт МГНОВЕННЫЙ пересчёт и перерисовку в браузере. Если пользователь должен
нажать кнопку и ждать результат — это не живой виджет, это форма. Переделать.

## 1. Тактильность и отклик (distill-bar)
- [ ] Что-то можно **тянуть, крутить или двигать** (не только ползунки-числа).
- [ ] Отклик < 1 кадра (rafThrottle); при перетаскивании картинка движется за курсором.
- [ ] Виджет рисует осмысленное состояние СРАЗУ при загрузке (draw() в билдере), без действий.
- [ ] Непрерывные процессы (отжиг, релаксация, колебания) идут сами через `S.loop`, а
      пользователь их *подкручивает*, а не *запускает*.

## 2. Визуальное качество
- [ ] Палитра Сигмы: blue #1F4E79 / red #C0392B / green #2E7D5B / gold / purple; фон #fffff8.
- [ ] Сериф (Palatino/Georgia) в подписях canvas; tabular-nums в read-out.
- [ ] Ничего не наезжает, не обрезается, не вылезает за рамку; оси/подписи читаемы.
- [ ] Чёткость на retina (deviceScaleFactor=2 — makeCanvas это обеспечивает).
- [ ] Адаптив: на ширине 360–600px не ломается, контролы переносятся.
- [ ] Нет «кринжа»: не рисуем реалистичные объекты примитивами (лица из кружков и т.п.);
      либо реальные данные, либо честная абстрактная схема. (Инцидент: синтетические
      гауссовы «лица» в eigenfaces → заменены на реальные Olivetti.)

## 3. Педагогика
- [ ] Виджет показывает РОВНО ту идею, что в тексте сюжета, и усиливает её.
- [ ] Есть hint сверху (как взаимодействовать) и caption снизу (что видим).
- [ ] Read-out показывает ключевые величины и обновляется вживую.
- [ ] Крайние/«ломающие» состояния поучительны, а не баг (резонанс, переинтерполяция, T→0).

## 4. Корректность математики
- [ ] Формулы и численные методы верны (сверить с эталоном Python при сомнении).
- [ ] Нет деления на ноль, NaN, расходимостей при крайних значениях ползунков.
- [ ] Никаких внешних библиотек и numpy: всё на чистом JS (в браузере numpy НЕТ).

## 5. Инженерия
- [ ] Файл = один `SigmaInt.register(...)`; использует только `S.*` и стандартный DOM/canvas.
- [ ] `node --check` проходит; в браузере **0 console-error** (проверка verify_widget.py).
- [ ] verify_widget.py: `reactsToSlider=true`, `hasCanvas`/`hasSvg`, `err=null`.
- [ ] Данные (если нужны) — git-tracked JSON в `docs/assistant/data/`, считаются один раз
      через `scripts/precompute_interactive.py`, НЕ на каждом билде.

## Процесс ревью (как доводим до готовности)
1. Собрать бандл: `bash scripts/build_interactive.sh`.
2. Отрендерить сюжет: `cd book && quarto render story_X.qmd --to html`.
3. Браузерная проверка: `/root/.venv/bin/python scripts/verify_widget.py <url> /tmp/sigverify`.
4. **Глазами** открыть скриншоты `_before/_after` (инструмент Read) — оценить по п.1–4.
   Чистый `report.json` ≠ красиво. Смотреть всегда.
5. Adversarial-критик (роль скептика distill.pub): найти ближайшую к кринжу/непонятности
   деталь и одну конкретную правку, повышающую планку. Применить. Повторять, пока чисто.
6. Готово = сам открыл, сам покрутил (в headless с эмуляцией ввода), верифицировал
   конкретный элемент. «Отправил скриншот» ≠ «готово».

## Где что лежит
- Ядро API: `scripts/interactive/core.js` (объект `S`).
- Виджеты: `scripts/interactive/widgets/*.js` (по одному на виджет).
- Бандл: `docs/assistant/interactive.js` (генерится `build_interactive.sh`, инъектится nginx).
- Данные: `docs/assistant/data/*.json` (`precompute_interactive.py`).
- Верификация/ревью: `scripts/verify_widget.py`.
