# AI Textbook Prototype

Минимальный демонстратор онлайн-компаньона школьного учебника информатики.

**Идея**: ученик выделяет фрагмент текста → появляется кнопка «Спросить» → ИИ отвечает по контексту фрагмента + общим знаниям.

## Что внутри
- `index.html` — одностраничник: оформленная глава 2 «От нейрона до нейронной сети» + выделение текста + модалка с вопросом.
- `server.py` — Python (stdlib, без зависимостей). Раздаёт статику и проксирует `/api/ask` → OpenRouter. `/api/model` тянет текущую лучшую бесплатную модель с `shir-man.com/api/free-llm/top-models`.

## Запуск
```bash
export OPENROUTER_API_KEY=sk-or-...
python3 server.py
# http://localhost:8765/
```

Переменные:
- `OPENROUTER_API_KEY` — обязательна для `/api/ask`.
- `PORT` (по умолчанию 8765), `HOST` (0.0.0.0).

## Что показать на встрече
1. Открыть страницу — обычный «бумажный» вид учебника.
2. Выделить любую фразу → кнопка «✦ Спросить» рядом с курсором.
3. В модалке — три квика («Объясни проще», «Пример из жизни», «Задача с решением») + произвольный вопрос.
4. Модель в шапке обновляется автоматически (берём топ-1 бесплатную с shir-man).
