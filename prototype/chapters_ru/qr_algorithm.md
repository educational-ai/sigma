QR-алгоритм — один из наиболее элегантных и мощных методов вычислительной линейной алгебры для нахождения собственных чисел матриц. Прелесть алгоритма заключается в его простоте и теоретической глубине: посредством итеративных QR-разложений он сходится к треугольной (или диагональной — для симметричных матриц) форме, обнажая собственные числа на диагонали.

## Описание алгоритма

Базовая QR-итерация устроена следующим образом:

1. Начинаем с матрицы $A_0 = A$
2. Для $k = 0, 1, 2, \ldots$ :
   - Вычисляем QR-разложение: $A_k = Q_kR_k$
   - Формируем следующую итерацию: $A_{k+1} = R_kQ_k$

Для симметричных матриц этот процесс сходится к диагональной матрице, содержащей собственные числа. Для произвольных матриц он сходится к верхнетреугольной форме Шура, где диагональные элементы по-прежнему являются собственными числами. ## Основные свойства

1. **Сохранение собственных чисел**: Каждая итерация $A_{k+1} = R_kQ_k$ подобна $A_k$, а потому сохраняет собственные числа.
2. **Сходимость**: Для симметричных матриц алгоритм сходится к диагональной матрице.
3. **Численная устойчивость**: Использование ортогональных преобразований обеспечивает хорошие численные свойства.

QR-алгоритм лежит в основе современных вычислений собственных чисел и реализован в большинстве библиотек вычислительной линейной алгебры. Хотя базовая версия, представленная здесь, элегантна, практические реализации используют различные усовершенствования — такие как сдвиги и сжатия — для повышения эффективности.
