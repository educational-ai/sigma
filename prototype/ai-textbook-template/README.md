# Учебник по ИИ для 10–11 классов — TeX-шаблон

Шаблон полноценного учебника на русском языке, с одним полностью
оформленным параграфом — «Метод касательных Ньютона и его
приложения» (раздел 2.1).

## Структура проекта

```
.
├── main.tex             — главный файл книги (титул, части, оглавление)
├── structure.tex        — преамбула: пакеты, шрифты, окружения, стили
├── chapters/
│   ├── preface.tex      — предисловие
│   ├── ch01_intro.tex   — глава 1 (заготовка)
│   ├── ch02_newton.tex  — глава 2: метод Ньютона (полностью оформлена)
│   └── ch03_ml.tex      — глава 3 (заготовка)
├── figures/             — PDF-графики, генерируемые make_figures.py
│   ├── newton_geometry.pdf
│   ├── taylor_parabola.pdf
│   ├── sqrt_convergence.pdf
│   └── reciprocal_convergence.pdf
├── make_figures.py      — Python-скрипт генерации графиков (matplotlib)
├── main.pdf             — собранная книга (18 страниц)
└── README.md            — этот файл
```

## Сборка

Шаблон **компилятор-агностичен**: он одинаково собирается под
**pdfLaTeX**, **XeLaTeX** и **LuaLaTeX**. Преамбула автоматически
определяет компилятор через пакет `iftex` и подключает нужные
пакеты:

* под **pdfLaTeX** используется классический путь —
  `cmap` + `inputenc{utf8}` + `fontenc{T2A,T1}` + `babel{russian}` +
  `lmodern` (Latin Modern в кодировке T2A);
* под **XeLaTeX/LuaLaTeX** — современный путь
  `polyglossia` + `fontspec` с Unicode-шрифтами OpenType.

### В Overleaf

Просто загрузите архив (`New Project → Upload Project`) и нажмите
**Recompile**. Никаких настроек компилятора менять не нужно —
по умолчанию Overleaf использует pdfLaTeX, и шаблон под ним собирается.

> Для более красивой типографики (с CMU Serif вместо Latin Modern)
> можно переключиться на XeLaTeX: `Menu → Settings → Compiler → XeLaTeX`.
> Шаблон сам выберет нужную ветку преамбулы.

### Локально

Зависимости:

* TeX Live ≥ 2021 с пакетами:
  * **общие**: `geometry`, `amsmath`, `amssymb`, `amsthm`,
    `mathtools`, `bm`, `xcolor`, `graphicx`, `tikz`, `pgfplots`,
    `caption`, `fancyhdr`, `titlesec`, `hyperref`, `bookmark`,
    `cleveref`, `tcolorbox`, `listings`, `microtype`, `iftex`;
  * **для pdfLaTeX**: `cm-super`, `babel-russian` (в пакете
    `texlive-lang-cyrillic` под Debian/Ubuntu);
  * **для XeLaTeX/LuaLaTeX**: `polyglossia`, `fontspec`, желательно
    `cm-unicode` (даёт CMU Serif/Sans/Typewriter с кириллицей).
* Python ≥ 3.8 + `numpy`, `matplotlib` — только если нужно
  пересобрать графики.

Команды:

```bash
# (опционально) пересобрать графики
python3 make_figures.py

# сборка PDF — три прохода нужны для оглавления и cross-references
pdflatex main.tex   # либо xelatex / lualatex
pdflatex main.tex
pdflatex main.tex
```

### Шрифты под XeLaTeX/LuaLaTeX

Шаблон содержит **fallback-цепочку** для шрифтов: он автоматически
выбирает первый доступный из:

* для основного текста: `CMU Serif → Libertinus Serif →
  Linux Libertine O → PT Serif → Liberation Serif → Latin Modern Roman`;
* для заголовков: `CMU Sans Serif → Libertinus Sans → PT Sans →
  Liberation Sans → Latin Modern Sans`;
* для кода: `CMU Typewriter → Libertinus Mono → PT Mono →
  Liberation Mono → DejaVu Sans Mono → Latin Modern Mono`.

На Overleaf обычно ловится **CMU Serif** (классический вид Computer
Modern с поддержкой кириллицы). Никаких ручных настроек не требуется.

## Возможности шаблона

**Математика.** Полная поддержка `amsmath`/`mathtools`. Нумерованные
формулы, выровненные блоки, окружения теорем и определений на базе
`tcolorbox` (рамки в фирменных цветах).

**Графика.** Включены `tikz`, `pgfplots`. Подключение готовых
PDF-рисунков через `\includegraphics{...}`; ищутся в `figures/`.

**Гиперссылки.** Настроен `hyperref` с цветными ссылками на
формулы (`\eqref{...}`), главы (`\ref{ch:...}`), разделы и URL.
Указатель PDF («закладки») формируется автоматически. В тексте
параграфа продемонстрированы внешние ссылки (`\url{...}`,
`\href{...}{...}`).

**Листинги кода.** Окружение `lstlisting` со стилем `pythonstyle`
(подсветка синтаксиса, левая полоса фирменного цвета).

> **Замечание о кириллице в коде.** Пакет `listings` под pdfLaTeX
> не умеет работать с UTF-8 кириллицей внутри блоков кода — это
> известная неудобная особенность. Поэтому комментарии в листинге
> Python даны по-английски, а пояснение к ним на русском вынесено
> в основной текст перед листингом. Под XeLaTeX/LuaLaTeX кириллица
> внутри `lstlisting` работала бы, но мы выбрали единый стиль ради
> совместимости с любым компилятором.

**Окружения-«врезок».** В `structure.tex` определены:

| Команда | Назначение |
|---|---|
| `\begin{theorem}{Заголовок}{label}` | теорема |
| `\begin{definition}{Заголовок}{label}` | определение |
| `\begin{example}{Заголовок}{label}` | пример (красная рамка) |
| `\begin{historybox}` | историческая справка |
| `\begin{notebox}` | примечание / замечание на полях |
| `\begin{tasksbox}` | список задач для самостоятельной работы |
| `proof` | доказательство (стандартное `amsthm`) |

Все теоремоподобные окружения нумеруются сквозным счётчиком
внутри главы (например, «Теорема 2.1», «Определение 2.4»).

## Параграф 2.1 — что внутри

Полностью разобраны все требования технического задания:

1. **Историческая справка** (Ньютон, Рафсон, **Канторович**),
   геометрическая интерпретация — метод касательных, рисунок с
   тремя итерациями, явная формула $x_{k+1}=x_k-f(x_k)/f'(x_k)$.
2. Вариант для **оптимизации** через ряд Тейлора до второго
   члена и принцип «**разделяй и властвуй**» (минимизация
   квадратичной модели).
3. **Пример 1**: метод Герона (с вавилонской табличкой YBC 7289),
   доказательство через **сжимающее отображение** и теорему Банаха,
   расчёт расстояния до горизонта.
4. **Пример 2**: метод Ньютона–Шульца для $1/a$, явная формула
   ошибки $u_k = u_0^{2^k}$, упоминание оптимизатора **Muon**.
5. **Python-код** общего метода + графики глобальной (Герон) и
   локальной (Ньютон–Шульц) сходимости с явным указанием радиуса
   $(0,\,2/a)$.
6. **Теорема о сверхлинейной (квадратичной) сходимости** с
   полным доказательством через рекуррентность для расстояния;
   разобрано, для какого из двух примеров и в какой области
   условия теоремы выполняются.
7. Блок задач — пять задач разной сложности, две со звёздочкой.

## Адаптация шаблона

* **Сменить шрифт.** Под XeLaTeX/LuaLaTeX в `structure.tex` достаточно
  изменить аргумент `\setmainfont{...}` (или поменять порядок
  fallback-цепочки). Подойдут: `CMU Serif`, `Libertinus Serif`,
  `PT Serif`, `STIX Two Text` — любой шрифт с кириллицей.
* **Сменить акцентный цвет.** Внутри `structure.tex` задано
  `\definecolor{accent}{HTML}{1F4E79}` и `\definecolor{accent2}{...}`.
* **Добавить главу.** Создайте файл `chapters/chXX_name.tex`,
  начните его с `\chapter{...}` и подключите в `main.tex` строкой
  `\input{chapters/chXX_name}` внутри подходящей `\part{...}`.
* **Добавить главу с библиографией BibTeX.** Подключите `biblatex`
  в `structure.tex` и замените раздел «Литература и веб-ресурсы»
  в `main.tex` на `\printbibliography`.
