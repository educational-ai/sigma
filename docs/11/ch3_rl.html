Содержание

Марковские цепи и случайные блуждания

  • Введение через PageRank (Гугл)
  • Случайные блуждания
  • ★ Диффузионный скейлинг и Винеровский процесс как предел случайных блужданий

MCMC

  • Методы Монте-Карло на основе цепи Маркова
  • Алгоритм Метрополиса–Хастингса
  • Пример Перси Диакониса — расшифровка текста (связь с работой LLM: предсказание следующего токена)

Управляемые процессы Маркова

  • ★ Уравнение Вальда–Беллмана
  • Обучение с подкреплением на примере задачи о многоруких бандитах
  • ★ Индексы Гиттинса
  • ★ Задача о разборчивой невесте (вероятностная модель + уравнение Беллмана)

Q-learning и нейросетевые подходы

  • Q-learning (без модели)
  • ★★ A2C, actor / critic, SAC, TD3+BC, SAC-N
  • ★★ Meta-RL: RL², MAML
  • Аппроксимация value function / policy через нейросеть
  • GRPO
  • ★ Пример: игра с самим собой, AlphaGo и AlphaZero
