Как мы оцениваем

«Чисто пройдено» = агент вызвал нужные инструменты и в ответе есть все обязательные ключевые элементы (чего не хватило — видно в карточке вопроса). Ответы, которых эвал так и не получил (модель/API не вернули ничего после ретраев, потолок 480 с) или оборвались огрызком (<40 символов), считаются оборванными (DNF — эвал не достал ответ, а не модель ошиблась), а не пройденными — даже если формально совпали по подстроке. Числовые ответы сверяются по самостоятельному числу, а не по цифре, случайно совпавшей внутри другого числа, — иначе неверный результат прошёл бы по совпадению. Вычислительные кейсы (расчёты, графики) грейдит код по точным числам/хэшам; смысловые (определения, теория, отказы, multi-hop) — состязательные Claude-судьи (судья → адверсариальный рефутер → критик легитимности): незачёт за галлюцинацию факта, сломанную формулу (которую KaTeX не отрендерит) и треш-стиль, негодный для учебника.
